# AI 视频学习笔记

> 截止 2026-09-25。第一期对齐 NoteGPT 落地页。完整方案见 [07-AI学习笔记细化方案.md](./07-AI学习笔记细化方案.md)。下载见 [05](./05-视频下载功能总结.md)。

## 1. 交付了什么

解析出封面标题后，用户可点「生成学习笔记」，得到：

- 总览
- 带时间戳的章节大纲
- 核心知识要点
- 树状思维导图
- 字幕原文
- 复制 Markdown、导出 `.md` / Word 兼容 `.doc`

不必先把视频下到本地。

## 2. 用户路径

```text
粘贴链接 → 解析成功 → 生成学习笔记 → 切换大纲/要点/脑图/字幕 → 复制或导出
同时仍可在上方选清晰度下载原片
```

## 3. 依赖

1. 视频有**官方或自动字幕**（B 站、YouTube 讲解课最稳）。
2. 把 `backend/.env.example` **复制为** `backend/.env`，只在 `.env` 填写 Key。example 必须保持空值，禁止填真实密钥。

```
DEEPSEEK_API_KEY=
```

对齐 [DeepSeek API 文档](https://api-docs.deepseek.com/)（2026-09）：

- Base URL：`https://api.deepseek.com`（请求 `POST /chat/completions`）
- 默认模型：`deepseek-flash`（也可用 `deepseek-v4-pro`）
- 结构化笔记启用 [JSON Output](https://api-docs.deepseek.com/guides/json_mode)，并关闭默认 [Thinking](https://api-docs.deepseek.com/guides/thinking_mode)

Key 在 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请。改 `.env` 后需重启 uvicorn。`GET /api/health` 的 `llm` 为 `true` 表示 Key 已读到。

## 4. 做不到的（第一期）

- 无字幕视频、多数抖音：**明确失败**，不做语音转写。
- 大纲时间戳只展示，不跳播、不内嵌播放器。
- 不对视频追问、不做画面理解、不改写成公众号。
- 无账号配额；费用走 DeepSeek 账单。

## 5. 关键代码

| 路径 | 职责 |
|------|------|
| `backend/services/captions.py` | 选字幕、解析 VTT/SRT/json3/B 站 JSON |
| `backend/services/llm.py` | Chat Completions |
| `backend/services/notes.py` | 结构化字段与 Markdown |
| `backend/api/video.py` | `POST /api/video/summarize` |
| `frontend/src/components/VideoStudyNotes.vue` | 笔记 UI |

## 6. 测试

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

含字幕解析与 summarize API 的 mock。联网验收请用一条**带字幕**的 B 站或 YouTube 讲解。

# 视频下载功能总结

> 截止 2026-09-25。MVP **链接解析 + 选清晰度 + 保存到本地** 已完成并在本地联调通过。细节契约见 [03-设计文档.md](./03-设计文档.md)，产品与后端差异见 [04-实现与产品差异.md](./04-实现与产品差异.md)。

## 1. 交付了什么

用户在网页（`http://localhost:5173`）粘贴公开视频链接或抖音分享口令 → 看到封面、标题、清晰度 →「开始下载」保存到本机。无需注册。界面不展示 server / 直链等术语。

已实测走通：

| 平台 | 结果 |
|------|------|
| YouTube | yt-dlp 解析；高清常为视频+音频两路再合并 |
| B 站 | 同上 |
| 抖音 | Playwright 解析 + httpx 拉 CDN；分享口令、`/video/{id}`、用户页 `modal_id` 可用 |

合规：页脚提示学习研究、尊重版权；不提供破解会员。

## 2. 用户路径

```text
粘贴链接或口令 → 开始（解析）→ 确认封面标题 → 选清晰度 → 开始下载 → 浏览器保存
```

- 解析失败：提示可读错误，可换链接。
- 下载失败：已解析结果保留，不必重新粘贴。
- 输入框为普通文本，可贴「复制打开抖音…」整段口令。

**不要贴**：`https://www.douyin.com/?recommend=1` 这类推荐首页（没有作品 id）。

## 3. 架构（谁干活）

```text
浏览器 SPA  ──/api──►  FastAPI
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
     抖音域名         其他平台         策略 choose_mode
          │               │
    Playwright        yt-dlp
    抽播放直链         extract / download
          │               │
    httpx 落盘        ffmpeg 合并（如需）
          └─────── downloads/{task} ──► GET /file
```

- 前端：Vue 3 + Vite + Tailwind，开发期把 `/api` 转到 `127.0.0.1:8000`。
- 后端：FastAPI；任务目录与代理 token 在内存，进程重启即失效。
- **无头 Chrome 跑在服务器上**，不在访客浏览器里。上线后其他用户贴抖音链接，用的是机房里的 Playwright，不必导出 Cookie。

## 4. 平台必须分开（踩过的坑）

| | YouTube / B 站 | 抖音 |
|--|----------------|------|
| 解析 | `yt-dlp extract_info` | `services/douyin_browser.py` |
| 下载 | `yt-dlp download`（常两路+ffmpeg） | httpx GET 直链 |
| Cookie / TLS 伪装 | **不带** | 仅 yt-dlp **回退** 时可用 `backend/cookies.txt` |
| 下载时再解析一遍 | auto 下跳过第二次 `get_info` | 走缓存，不再二次开浏览器 |

判断用 **域名**（`is_douyin_url`），不能用整段 URL 是否包含字符串 `douyin.com`。

曾出现的问题：把抖音 `cookies.txt` 配进所有 yt-dlp 请求 → B 站/油管变慢；下载接口再 `get_info` 一次 → 等待翻倍。已修。

## 5. 抖音为什么单独做

yt-dlp 打抖音网页详情接口，无新鲜访客 Cookie 时常返回空 JSON（`Fresh cookies are needed`）。Windows 上 Chrome 127+ 还加密 Cookie，yt-dlp 很难直接读本机浏览器。

现行主路径：服务器开 Chromium，打开作品页，按 **作品 id** 和 **画面最大的播放器** 取 `douyinvod` 地址，避免推荐流里旁边那条（曾误下约 200KB 短片）。

链接处理（`url_normalize.py`）：

- 口令里抽出 `v.douyin.com` / `douyin.com`
- `/user/...?modal_id=` 改写成 `/video/{id}`

失败才回退 yt-dlp + 可选 Cookie。主路径不依赖站长天天导出 Cookie。

给其他用户用：部署机必须 `pip install -r requirements.txt` 且 `python -m playwright install chromium`，并用**同一虚拟环境**启 uvicorn。内存要够开无头 Chrome。抖音看的是 **服务器 IP**，并发高或风控时仍可能失败。

## 6. 下载策略（用户无感）

`choose_mode`（`download_strategy.py`）：

- 分片 / 音视频分离 / 无直链 → `server`
- YouTube、B 站、抖音等直链不稳 → `server`
- 否则 `redirect` 或带 Header 的 `proxy`

前端固定 `prefer_mode: auto`，并带上当前清晰度的 `stream_kind`（是否 merge）。

本地 server 模式：磁盘上可能短暂两份（`downloads/` + 用户保存目录），约 1 小时 TTL。见 [04](./04-实现与产品差异.md)。

## 7. 关键代码

| 路径 | 职责 |
|------|------|
| `frontend/src/App.vue` | 解析/下载状态机 |
| `frontend/src/api/video.js` | `/api/video/info`、`/download` |
| `backend/api/video.py` | HTTP：info / download / file / proxy |
| `backend/services/downloader.py` | 平台分流、缓存、落盘 |
| `backend/services/douyin_browser.py` | Playwright 抽链 |
| `backend/services/url_normalize.py` | 口令与 modal 链接 |
| `backend/services/download_strategy.py` | 模式选择、B 站/油管跳过二次解析 |
| `backend/config.py` | 直链不可靠平台列表等 |

## 8. 本地怎么跑

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m playwright install chromium
python -m uvicorn main:app --reload --port 8000
```

另开终端：`cd frontend && npm run dev` → <http://localhost:5173>

单测：`python -m unittest discover -s tests -v`  
（含 strategy、format_list、url_normalize、平台隔离、抖音选链、字幕解析、notes part mock、DeepSeek payload）

AI 学习笔记见 [06-AI学习笔记功能总结.md](./06-AI学习笔记功能总结.md)。

## 9. 已知限制

- 仅公开可访问内容；会员/私密不行。
- 抖音每次解析约十几秒；验证码/风控会失败。
- YouTube/B 站高清要 ffmpeg，耗时主要是拉流+合并，不是 Playwright。
- Cookie 文件、下载目录已 gitignore，**不要提交** `backend/cookies.txt`、`backend/downloads/`。
- 上线需公网能打到 API，不能只发静态前端。

## 10. 以后不要做的事

- 不要把 Playwright 或抖音 Cookie 套到 YouTube/B 站。
- 不要为「加速」在下载时对抖音再开一次浏览器（应走解析缓存）。
- 不要用推荐流第一条视频当地址（必须对作品 id / 主播放器）。

# 设计文档：万能视频下载网站

> 产品与实现差异见 [04-实现与产品差异.md](./04-实现与产品差异.md)。

## 1. UI 设计

### 1.0 设计稿

- 可选维护 [design.pen](./design.pen)；**与代码不一致时以 `frontend/` 与 `tailwind.config.js` 为准**。设计稿偏下载 MVP 首屏；解析成功后的双栏工作台、Tab 切换以 `App.vue` 为准。

### 1.1 参考与调性

- **气质参考**：[鱼皮 AI 绘图导航](https://ai.codefather.cn/painting)（居中搜索、卡片、工具产品感）。
- **当前实现**：白/浅灰底、**单色 accent `#2563EB`**、Geist/Inter 标题、**全页柔和径向光斑**（无首屏与能力区之间的硬分割背景）；文案偏 **「保存 / 学习 / 问」**，少技术术语。首屏无 Eyebrow、无信任标签行。

### 1.2 布局结构

**未解析**（`idle` / `parsing` / 解析失败 / 服务不可用；`showSteps === true` 时展示能力区）：

```text
┌─────────────────────────────────────┐
│ Nav: Logo + 站点名                   │
├─────────────────────────────────────┤
│ Hero: 标题 + 副标题（居中，max-w-content）│
│ [ 粘贴链接 pill 搜索 ]                 │
│ StatusAlert / ResultSkeleton         │
│ HowItWorks：kicker + 标题 + 三能力卡片 │
├─────────────────────────────────────┤
│ Footer                               │
└─────────────────────────────────────┘
```

**已解析**（`ready` / `downloading` / `downloadError`）：**隐藏 Hero 大标题**，顶栏下为「已识别 + 链接摘要 + 更换链接」，主体 **双栏**（`max-w-[1200px]`，`lg` 约 `320–400px | 1fr`）：

```text
┌────────────────────────────────────────────────────────────┐
│ Nav                                                        │
│ [ 已识别 | 链接… | 更换链接 ]                               │
├──────────────────────┬─────────────────────────────────────┤
│ 左栏（lg sticky）     │ 右栏工作台（圆角卡片，内滚动）        │
│ VideoResult embedded │ Tab：学习笔记 | 问AI                 │
│ 封面/清晰度/下载      │ VideoStudyNotes inset / VideoAsk pane │
└──────────────────────┴─────────────────────────────────────┘
```

右栏在宽屏下高度约 `calc(100dvh - 10rem)`，避免笔记与问答纵向无限拉长。`App.vue` 内 `studyPane` 切换 Tab；换链接重置为「学习笔记」。

**首屏 Hero 文案（`COPY`，仅 `!info` 时展示）**

| view | 标题（示例） | 副标题（示例） |
|------|----------------|----------------|
| idle / parsing | 贴上链接，留下文件，也留下理解。 | 公开视频贴进来就能下。有字幕的，还能整理大纲、要点，并针对这条视频提问。 |
| parseError / serviceDown / … | 见 `App.vue` `COPY` | 同上文件 |

`ready` / `downloading` 等状态文案仍在 `COPY` 中维护，但解析成功后界面**不再展示** Hero，以免与双栏工作台抢视线。

**HowItWorks 三卡说明**（`HowItWorks.vue`）：保存文件 / 学习笔记 / 问AI，副文案分别为「选清晰度，一键下载去水印视频到本机。」「大纲、要点、脑图、字幕都能生成。」「针对这条视频向AI提问。」

**不在界面展示**：`recommended_mode` Tag、自动/强制服务端/优先直链、`FeatureCards` 三卡网格。

|-------|-----------|

### 1.4 组件划分（Vue）

| 组件 | 职责 |
|------|------|
| `UrlSearch.vue` | 搜索条；`type=text`，可粘贴分享口令；emit `parse`、暴露 `focus()` |
| `VideoResult.vue` | 封面/标题/平台标签、清晰度下拉、`prefer_mode: 'auto'` + `stream_kind` 下载；`embedded` 用于左栏 |
| `VideoStudyNotes.vue` | 四按钮分块生成；已生成的块以 Tab 切换；复制与导出 md；大纲/要点/字幕可导出 doc；脑图 Tab 导出 PNG、不提供 Word；`embedded` + `inset` 时隐藏卡片外标题 |
| `VideoAsk.vue` | 输入框 + 多轮气泡；换链接清空；`embedded` + `inset` + `pane` 时占满右栏 Tab 内容区 |
| `MindMapCanvas.vue` | 只读思维导图画布（Mind Elixir）；全屏查看；浏览器导出 PNG |
| `StatusAlert.vue` | 统一错误/警告条（tone + title + detail） |
| `ResultSkeleton.vue` | 解析等待占位 |
| `HowItWorks.vue` | 未解析时三能力卡（文案见 1.2） |
| `App.vue` | 状态机 `view`、Hero 文案 `COPY`、`studyPane` Tab、双栏布局、下载走 `api/video.js` |

### 1.5 交互状态

- **解析中**：Hero 保持；`ResultSkeleton`；搜索按钮 loading。
- **解析成功**：搜索区变为「已识别 + 更换链接」；双栏展示下载与右侧 Tab（默认「学习笔记」）；隐藏 `HowItWorks` 与 Hero 大标题。
- **下载中**：左栏主按钮「正在准备下载…」；后端完成后 `window.location.href` 触发浏览器保存（server/proxy 用 `download_url`，redirect 用 `redirect_url`）。
- **错误**：`StatusAlert`（解析失败 / 下载失败 / 后端不可用）；下载失败时保留已解析结果，无需重新粘贴链接。
- **清晰度**：下拉展示 `resolution` + `约 size · 含声音|视频+音频合并|仅音频`（来自 `stream_kind`）。

## 2. API 设计

Base URL（开发）：浏览器请求 `/api/...`，由 Vite 代理到 FastAPI。

### 2.1 通用约定

- Content-Type：`application/json`
- 错误：`HTTP 4xx/5xx` + body `{ "detail": "..." }` 或 FastAPI 默认 `detail` 数组

### 2.2 POST `/api/video/info`

**Request**

```json
{ "url": "https://..." }
```

**Response 200**

```json
{
  "title": "string",
  "thumbnail": "string | null",
  "duration": 0,
  "extractor": "string",
  "webpage_url": "string",
  "recommended_mode": "server | redirect | proxy",
  "recommended_reason": "string",
  "formats": [
    {
      "format_id": "string",
      "ext": "mp4",
      "resolution": "1080p",
      "filesize": 0,
      "vcodec": "string | null",
      "acodec": "string | null",
      "protocol": "https | m3u8 | ...",
      "stream_kind": "muxed | merge | audio"
    }
  ]
}
```

**说明**

- `formats`：后端 `list_user_formats()` 过滤去重，最多约 40 条。
- `stream_kind`：`muxed` 音画同轨；`merge` 仅视频轨（下载时服务端合并音频）；`audio` 仅音频。
- `recommended_*`：**当前前端不展示**，供日志/后续「换方式重试」使用。

### 2.3 POST `/api/video/download`

**Request**

```json
{
  "url": "https://...",
  "format_id": "137",
  "prefer_mode": "auto",
  "stream_kind": "merge"
}
```

`prefer_mode`: `auto` | `server` | `direct` — **MVP 前端固定 `auto`**。`stream_kind` 可选，前端把当前清晰度类型带上，供 B 站/油管下载时判断是否合并、并跳过第二次解析。

**Response 200（union）**

含 `mode`、`filename`；以及 `download_url` 或 `redirect_url`；server 模式含 `expires_at`。直链失败回退 server 时 `fallback: true`、`reason` 可选 — **前端当前不展示**。

### 2.4 GET `/api/video/file/{task_id}`

- 成功：`FileResponse`，`Content-Disposition: attachment`
- 404：任务不存在或已过期

### 2.5 GET `/api/video/proxy/{token}`

- 短期 HMAC token；`StreamingResponse` 流式转发（Range 未实现）
- 403：token 无效或过期

### 2.6 GET `/api/health`

```json
{ "status": "ok", "ffmpeg": true }
```

笔记是否配 Key 看下面的 `GET /api/notes/ready`，不要写进本接口。

### 2.7 GET `/api/notes/ready`

```json
{ "llm": false, "llm_model": null }
```

### 2.8 POST `/api/notes/summarize`

**Request**

```json
{ "url": "https://...", "part": "outline" }
```

`part`：`outline` | `points` | `map` | `transcript`。

**Response 200**

`part`、`title`、`webpage_url`、`language`、`source`（`official` | `auto`）、`markdown`；以及当前块的 `outline[]` / `key_points[]` / `mind_map` / `transcript[]`（其余为空）。

**错误**

- 422：缺少 `part`
- 503：大纲/要点/脑图且未配置 DeepSeek Key（用户文案：笔记和问答暂时不可用。）
- 400：无字幕、解析失败
- 502：大模型调用失败

笔记不依赖先下载视频。契约细节见 [06-AI学习笔记功能总结.md](./06-AI学习笔记功能总结.md)。

### 2.9 POST `/api/notes/chat`

**Request**

```json
{ "url": "https://...", "messages": [{ "role": "user", "content": "这节课讲了什么" }] }
```

`messages` 1 到 16 条，`role` 为 `user` 或 `assistant`，最后一条必须是 `user`。单条最长 2000 字。

**Response 200**

```json
{ "reply": "..." }
```

**错误**

- 422：消息为空，或最后一条不是用户提问
- 503：未配置 DeepSeek Key
- 400：无字幕轨、字幕为空
- 502：大模型调用失败

问答与笔记共用字幕缓存。没有字幕时只在问答卡片失败，不改下载。历史由前端随请求带上，后端不落库。完整说明见 [08-AI视频问答功能总结.md](./08-AI视频问答功能总结.md)。

## 3. 后端模块设计

```text
backend/
├── main.py
├── config.py
├── api/video.py              # info / download / file / proxy
├── api/notes.py              # ready / summarize / chat

├── models/notes_schemas.py   # part / outline / mind_map / chat
├── services/
│   ├── downloader.py         # get_info, download, list_user_formats
│   ├── douyin_browser.py     # 仅抖音 Playwright
│   ├── url_normalize.py      # 抽链、modal_id → /video/id
│   ├── download_strategy.py  # choose_mode, skip_redownload_info_probe
│   ├── captions.py           # 字幕选择与解析
│   ├── llm.py                # OpenAI 兼容 Chat
│   ├── notes.py              # 结构化笔记、问答 prompt、Markdown
│   ├── task_store.py
│   └── proxy_token.py
├── tests/
│   ├── test_strategy.py
│   ├── test_format_list.py
│   ├── test_url_normalize.py
│   ├── test_platform_isolation.py
│   ├── test_douyin_pick_media.py
│   ├── test_captions_notes.py
│   ├── test_summarize_api.py
│   └── test_llm_deepseek.py
└── downloads/                # .gitignore；cookies.txt 亦 ignore
```

### 3.1 `VideoDownloader`

- `get_info(url)`：抖音先 Playwright；其他平台 yt-dlp
- `download(...)`：抖音 httpx 直链；其他平台 yt-dlp
- `list_user_formats(info)` → 含 `stream_kind`

下载策略与回退逻辑在 **`api/video.py`** + **`choose_mode()`**，无单独的 `execute_download` 模块。

### 3.2 配置（`backend/config.py`）

`FILE_TTL_SECONDS`、`MAX_CONCURRENT_DOWNLOADS`、`DIRECT_UNRELIABLE_EXTRACTORS`、`FRAGMENT_PROTOCOLS`、`CORS_ORIGINS`、`OPENAI_*`、`SUMMARIZE_MAX_CHARS`。

## 5. 数据流

```mermaid
sequenceDiagram
    participant U as User
    participant F as Vue
    participant B as FastAPI
    participant Y as yt-dlp
    participant P as Playwright

    U->>F: 粘贴 URL 或分享口令
    F->>B: POST /api/video/info
    alt 抖音
        B->>P: 打开页面取直链
    else 其他平台
        B->>Y: extract_info
    end
    B-->>F: formats + stream_kind
    U->>F: 选清晰度 + 开始下载
    F->>B: POST /api/video/download auto + stream_kind
    alt 抖音
        B-->>F: download_url（httpx 已落盘）
    else server
        B->>Y: download
        B-->>F: download_url
    else redirect or proxy
        B-->>F: redirect_url or proxy url
    end
    F->>U: 浏览器保存文件
```

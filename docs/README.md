## 给 AI 的使用说明

1. **了解当前已上线能力**：先读 `05`；学习笔记再读 `06`。
2. **改功能前**：再读 `01` 的范围、`07` 的笔记方案与 `04` 的产品差异。
3. **改下载逻辑**：以 `02` 与 `backend/services/download_strategy.py` 为准。YouTube/B 站继续薄封装 yt-dlp；**抖音走 Playwright**，不要把 Cookie/无头浏览器套到其他平台。
4. **改界面**：以 `03` 的组件表与 `frontend/tailwind.config.js` token 为准。
5. **新增 API**：更新 `03` API 章节，必要时同步 `02`、`05`、`06`。

# AI 视频问答功能总结

> 截止 2026-09-26。解析成功后即可对这条视频提问，**只依据字幕轨**，不必先生成学习笔记。下载见 [05](./05-视频下载功能总结.md)；笔记见 [06](./06-AI学习笔记功能总结.md)；产品边界见 [01](./01-需求分析.md)。

## 1. 交付了什么

解析成功后，**右栏工作台** Tab「问AI」内为对话区（与「学习笔记」切换；左栏仍为下载）。用户**不必先下载、也不必先点大纲 / 要点 / 脑图 / 字幕**。

| 界面 | 行为 |
|------|------|
| 入口 | 右栏 Tab「问AI」 |
| 输入框 | placeholder「输入你的问题」；Enter 发送，Shift+Enter 换行 |
| 空状态 | 说明只根据字幕回答；三条**固定**示例问法（补笔记做不到的：听漏的前提、例子在说明什么、判断 vs 事实），点一下写入输入框，不自动发送、不按视频生成 |
| 对话 | 多轮气泡；右蓝为自己，左灰为回答 |
| 换链接 / 刷新 | 本页历史清空，后端不保存 |

已实测：YouTube《Me at the zoo》官方英文字幕 → 连续两问，第二问能接着第一问（鼻子很长、觉得很酷）。

合规：不破解会员、不做语音转写、不内嵌播放器、不根据画面编造。

## 2. 用户路径

```text
粘贴公开链接 → 解析成功
  → 右栏可切到 Tab「问AI」（与「学习笔记」同时可用）
  → 空状态可点固定示例问法填入输入框，或自己打字
  → 输入问题并发送
  → 气泡先出现自己的问题，再出现回答
  → 可继续追问；同一条链接的字幕走现有进程内缓存
```

失败只写在问答卡片：没有字幕、未配 Key、模型超时。已解析结果和下载区留着。

## 3. 架构（谁干活）

```text
VideoAsk.vue
        │  POST /api/notes/chat  { url, messages }
        ▼
   FastAPI api/notes.py
        │
        ├─ 字幕缓存（与笔记同一套：captions.fetch_cues_for_url）
        │     官方优先，否则自动字幕；跳过弹幕；SUMMARIZE_MAX_CHARS 截断
        │
        └─ DeepSeek Chat Completions 纯文本
              thinking 关闭；不要 JSON Mode
              system = 标题 + 字幕；history 由前端随请求带上
```

- 路由仍挂 `/api/notes`，**不改** `/api/video`。
- 无数据库、对话不写 `downloads/`。
- 前端：`App.vue` 右栏 `VideoAsk`（`embedded` + `inset` + `pane`），与笔记 Tab 互斥展示、共用卡片高度。

## 4. 和竞品的差别（调研后砍掉的）

看过 [BibiGPT](https://bibigpt.co/) 结果页与 [NoteGPT B 站摘要样例](https://notegpt.io/cn/bilibili-summarizer)：

| 竞品常见能力 | 本工具第一期 |
|--------------|--------------|
| 内嵌播放器 + 点时间戳跳播 | 不做 |
| 按视频生成建议问题 | 不做；空状态只用固定示例问法填入输入框 |
| 无字幕走云 ASR | 不做；与笔记同一关 |
| 登录 / 配额 | 不做 |
| 附件、可拖拽聊天窗 | 不做 |

问答能不能答出来，**只看能不能拉到字幕轨**，和笔记同一套机制。

## 5. 字幕闸门

与 [06 第 4 节](./06-AI学习笔记功能总结.md) 相同：官方轨优先，否则自动字幕。烧在画面上的字、纯弹幕、多数抖音：用户看到同一句「这条视频没有字幕，暂时没法生成笔记或回答。」不区分内部原因。

送给模型的字幕按 `SUMMARIZE_MAX_CHARS`（默认 48000）截断。

## 6. DeepSeek 调用（问答 vs 笔记）

| 项 | 笔记（大纲/要点/脑图） | 问答 |
|----|------------------------|------|
| 接口 | 同一 `POST {base}/chat/completions` | 同左 |
| 模型 | `deepseek-flash` | 同左 |
| JSON Mode | 要 | **不要** |
| Thinking | 关闭 | 关闭 |
| 流式 | 否 | 否 |
| 无 Key | 503；字幕块仍可用 | 503；整张卡片不可用 |

Key 仍只放 `backend/.env` 的 `DEEPSEEK_API_KEY`（或 `OPENAI_API_KEY`）。是否配好看 `GET /api/notes/ready` 的 `llm`。页面不出现 DeepSeek、`.env`、Key 等词；无 Key 时写「问答暂时不可用。」

## 7. API 契约

### `POST /api/notes/chat`

请求：

```json
{
  "url": "https://...",
  "messages": [{ "role": "user", "content": "他的结论是什么" }]
}
```

`messages` 1～16 条，`role` 为 `user` 或 `assistant`，单条最长 2000 字，**最后一条必须是 user**。链接规范化与下载同一套。

成功 200：`{ "reply": "..." }`。

| HTTP | 何时 |
|------|------|
| 422 | 消息为空，或最后一条不是用户 |
| 503 | 无 Key（文案：笔记和问答暂时不可用。） |
| 400 | 无字幕、空字幕、拉字幕失败 |
| 502 | 超时、空 content、上游 4xx/5xx |

system 约束：只根据字幕回答；字幕没有的直说不知道，不要编画面或弹幕。

## 9. 本地怎么跑

与笔记相同：`backend/.env` 配 `DEEPSEEK_API_KEY` 后重启 uvicorn。单测：

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
python -m unittest discover -s tests -v
```

手工验收：配 Key，用**带 CC / 自动字幕**的 YouTube。解析后切到 Tab「问AI」连问两句，第二句应接着上一句。不必先点笔记按钮。无字幕视频只在问AI Tab 失败；左栏「开始下载」仍可用。

## 10. 已知限制

- 仅字幕轨；烧录字、弹幕、多数抖音不行。
- 答案不强制带时间戳，不能跳播。
- 对话只在当前页；刷新即没。
- 无账号、无配额 UI；费用走 DeepSeek 账单。
- 字幕缓存单进程内存，多 worker 不共享。

## 11. 以后不要做的事

- 不要为问答单独再拉一遍字幕；必须走 `fetch_cues_for_url` 缓存。
- 不要给问答开 JSON Mode；笔记继续用 JSON Mode。
- 不要把对话写入数据库或 `downloads/`。
- 不要在页面常驻「字幕轨 / 下载不受影响 / DeepSeek Key」这类内部说明。
- 不要把问答写进 `api/video.py`，不要改 `/api/health`。
- 不要默认接 ASR、按视频生成建议问题、附件、播放器跳播，除非单独开一期。

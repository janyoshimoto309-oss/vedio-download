# AI 学习笔记功能总结

> 截止 2026-09-27。第一期 **字幕轨 → 分块生成大纲 / 要点 / 脑图 / 字幕原文** 已完成；脑图页已改为只读画布（非缩进列表）。带官方 CC 的 YouTube 上联调通过。下载能力见 [05-视频下载功能总结.md](./05-视频下载功能总结.md)；产品边界见 [01-需求分析.md](./01-需求分析.md)。

## 1. 交付了什么

解析出封面标题后，**右栏 Tab「学习笔记」**内出现四块生成入口（左栏仍为下载区）。用户**不必先下载整片**。四个按钮各自生成一块：

| 按钮 | 来源 | 要 DeepSeek Key |
|------|------|-----------------|
| 生成大纲 | 字幕 + LLM | 要 |
| 生成要点 | 字幕 + LLM | 要 |
| 生成脑图 | 字幕 + LLM（JSON 树）→ 前端只读画布 | 要 |
| 生成字幕 | 只读字幕轨 | 不要 |

生成成功后出现对应 **Tab**，自动切到刚生成的那一块；已生成的仍可点 Tab 回看，不会竖排堆在一起。导出：复制、导出 Markdown（`.md`）。大纲 / 要点 / 字幕 Tab 另可导出 Word（`.doc`，HTML 另存，不是原生 docx）。**脑图 Tab 不提供 Word**，改为画布右上角「全屏查看」，以及「导出图片」（PNG，浏览器截当前脑图，不写 `downloads/`）。复制 / Markdown 里脑图仍是嵌套列表，当作文本备份。导出内容只含已经生成的块。界面不展示语言代码或「官方字幕 / 自动字幕」。

已实测走通：YouTube《Me at the zoo》官方英文字幕 → 四块均可生成。

合规：不破解会员、不做语音转写绕过「没字幕轨」。

## 2. 用户路径

```text
粘贴公开链接 → 解析成功（左栏封面、清晰度、下载；右栏默认「学习笔记」）
  → 点「生成大纲 / 要点 / 脑图 / 字幕」之一
  → 出现对应 Tab，只展示当前块
  → 再点另一个按钮：新 Tab 出现并跳过去；旧 Tab 还在
  → 复制或导出已生成部分（脑图可全屏、可另存 PNG）
```

失败只影响笔记卡片：无字幕、Key 未配（大纲/要点/脑图）、模型超时。已解析结果和下载体留着。

## 3. 架构（谁干活）

```text
VideoStudyNotes.vue
        │  POST /api/notes/summarize  { url, part }
        ▼
   FastAPI api/notes.py
        │
        ├─ 字幕缓存（按规范化 URL，进程内）
        │     captions.fetch_cues_for_url
        │       抖音：yt-dlp info + aweme / Playwright 补轨
        │       其他：yt-dlp 官方字幕，否则自动字幕
        │       解析 VTT / SRT / json3 / B 站 JSON；跳过弹幕
        │
        ├─ part = transcript  → 直接返回 cues，不调模型
        └─ part = outline | points | map
              → 截断字幕 → DeepSeek Chat Completions（JSON Mode）
              → 只填当前字段 + 该块 markdown
              → 前端 MindMapCanvas 把 mind_map JSON 画成只读脑图（不改 summarize 契约）
```

- 笔记路由挂在 `main.py` 的 `/api/notes`，**不改** `/api/video` 下载契约。
- 无数据库、不把笔记文件写进 `downloads/`。
- 前端：`App.vue` 右栏 `VideoStudyNotes`（`embedded` + `inset`），与问AI 共用 Tab 容器；宽屏下内容区可滚动，避免整页过长。

## 4. 字幕轨 ≠ 画面上的字（踩过的坑）

文本**只来自可下载的字幕轨**（官方优先，否则自动字幕）。语言偏好：简中 → 繁中 → 英 → 其余第一条。

| 现象 | 原因 | 结论 |
|------|------|------|
| 抖音「明明有字幕」失败 | 多为烧在画面上的字，没有 timedtext | 第一期失败，不做 ASR |
| B 站只有弹幕 | `danmaku` 不是字幕轨 | 跳过弹幕；没有其它轨就 400 |
| 油管轨道特别多、429 | 一次试太多条 timedtext | 最多试 8 条，遇 429 立刻停 |
| 空文件当成功 | 选到空轨 | 空轨跳过，换下一条 |

竞品（NoteGPT / BibiGPT）对无轨视频走**付费云 ASR**。本工具体量小，已明确不做本地 Whisper（长视频太慢）和云转写（工程量大）。

送给模型的字幕按 `SUMMARIZE_MAX_CHARS`（默认 48000）截断；`transcript` 这一块尽量给全量 cues。

返回给前端的笔记与字幕展示会做 **OpenCC 繁转简（t2s）**：繁体轨或模型跟写繁体时，大纲 / 要点 / 脑图 / 字幕 Tab 与导出 Markdown 统一为简体。问 AI 的回复同样转简。

## 5. 四块独立生成

早期一次 LLM 吐出总览+大纲+要点+脑图+字幕，等待长、失败全没。现行：

- 请求必须带 `part`：`outline` | `points` | `map` | `transcript`。缺 `part` → 422。
- **总览已去掉**，不再单独生成。
- 大纲 / 要点 / 脑图各打一次 DeepSeek，prompt 约束与原先相同，只要求当前 JSON 字段。
- 同一 URL 的字幕缓存在内存里，连点几个按钮不会反复打平台。进程重启缓存清空。

## 6. DeepSeek 调用（以官网为准）

文档：[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion)、[JSON Output](https://api-docs.deepseek.com/guides/json_mode)、[Thinking](https://api-docs.deepseek.com/guides/thinking_mode)。

| 项 | 取值 |
|----|------|
| 方法 | `POST https://api.deepseek.com/chat/completions` |
| 鉴权 | `Authorization: Bearer $DEEPSEEK_API_KEY` |
| 模型 | `deepseek-flash`（可改为 `deepseek-v4-pro`） |
| JSON Mode | `response_format: { "type": "json_object" }`，system 里必须出现 `json` |
| Thinking | `thinking: { "type": "disabled" }`（默认开启，结构化笔记必须关） |
| 其它 | `stream: false`，`max_tokens` 默认 8192 |

本地：只在 `backend/.env` 写 `DEEPSEEK_API_KEY`（也认 `OPENAI_API_KEY`）。**不要**写进会进 Git 的 `backend/.env.example`。改 `.env` 后重启 uvicorn。

是否配好 Key：看 `GET /api/notes/ready` 的 `llm`。**不要**往 `GET /api/health` 塞 `llm`（健康检查只含 `status` / `ffmpeg`，下载探测不能误报笔记状态）。

未配 Key：大纲/要点/脑图 503；字幕仍 200。模型失败 502。无轨 400。错误文案脱敏，不回传 Key。页面写「大纲、要点和脑图暂时不可用。字幕还可以看。」不出现 DeepSeek、`.env`。

问答（问AI）已拆到 [08-AI视频问答功能总结.md](./08-AI视频问答功能总结.md)，字幕闸门与本页第 4 节相同。

## 7. API 契约

### `GET /api/notes/ready`

```json
{ "llm": false, "llm_model": null }
```

### `POST /api/notes/summarize`

请求：`{ "url": "...", "part": "outline" }`（链接规范化与下载同一套）。

成功 200 公共字段：`part`、`title`、`webpage_url`、`language`、`source`（`official` | `auto`）、`markdown`。按 `part` 只填对应块，其余为空列表或 `mind_map: null`。

| HTTP | 何时 |
|------|------|
| 422 | 没有 `part` |
| 503 | 大纲/要点/脑图且无 Key |
| 400 | 无字幕轨、空轨、解析失败 |
| 502 | DeepSeek 超时、非 JSON、空 content、上游 4xx/5xx |

问AI 的 `POST /api/notes/chat` 见 [08 第 7 节](./08-AI视频问答功能总结.md)。

手工验收：配 Key 后用**带 CC / 自动字幕**的 YouTube（或有字幕轨的 B 站讲解）。先点大纲，再点要点，应出现两个 Tab 且能来回切。点脑图后应为中心放射图，不是缩进列表；「全屏查看」可关闭；「导出图片」能下 PNG；脑图 Tab 没有「导出 Word」。无轨视频应看到可读失败。点「开始下载」仍应能保存原片。问AI 的验收见 [08](./08-AI视频问答功能总结.md)。

## 10. 已知限制

- 仅公开视频上的**字幕轨**；烧录字幕、弹幕、多数抖音不行。
- 大纲时间戳只展示，不跳播、不内嵌播放器。
- 脑图 PNG 只在用户浏览器里生成，后端不存图；Markdown 里的脑图仍是列表，不是图片。
- 无账号、无配额 UI；费用走 DeepSeek 账单。
- 字幕缓存在单进程内存，多 worker 不共享。
- 上线用环境变量注入 Key，不要把 `.env` 打进镜像或前端包。

## 11. 以后不要做的事

- 不要为「像竞品一样有笔记」去接本地 Whisper 或云 ASR，除非单独开一期并接受耗时/账单。
- 不要把笔记逻辑写进 `api/video.py`，不要改下载健康检查字段。
- 不要一次 LLM 再吐回总览+四块；保持 `part` 分块。
- 不要把真实 Key 写进 `.env.example` 或提交 `backend/.env`。
- 不要把弹幕当字幕；不要为油管一次拉上百条字幕轨。
- 不要为笔记去重写已冻住的下载路径（`video.py` / `downloader` / `download_strategy`）。
- 不要让模型直接出脑图图片，也不要把 PNG 写入 `downloads/`；继续 `mind_map` JSON + 前端画布。
- 不要把 `mind-elixir` 打进首页同步包（`MindMapCanvas` 保持 `defineAsyncComponent`）。
- 不要给脑图 Tab 加回「导出 Word」。
